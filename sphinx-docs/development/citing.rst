Citing Prosemble
================

If Prosemble helps your research, please cite it:

.. code-block:: bibtex

   @misc{Otoo_Prosemble_2022,
     author       = {Otoo, Nana Abeka},
     title        = {Prosemble},
     year         = {2022},
     publisher    = {GitHub},
     journal      = {GitHub repository},
     howpublished = {\url{https://github.com/naotoo1/Prosemble}},
   }

Many models implement methods published by others. Their docstrings and
the user guide pages give the original references; please cite those
papers as well when you use the corresponding models.
